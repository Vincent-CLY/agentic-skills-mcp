# MASTER FRONTEND DESIGN, MOTION PHYSICS & ANTI-SLOP ENGINE

## 1. Anti-AI-Slop Hard Floor (`Impeccable` + `Unslop` + `Hallmark` + `taste-skill`)
1. **Banned AI Slop Patterns**:
   - NEVER use default purple/indigo/blue neon gradients, glowing blobs, emoji section headers, shouty marketing copy, generic centered 3-card icon grids, or fake "Lorem ipsum" copy.
   - NEVER invent arbitrary spacing or raw hex colors outside CSS variables/design tokens.
2. **Token, Palette & Aesthetic Setup (`Hallmark` / `taste-skill` / `ui-ux-pro-max`)**:
   - **Greenfield UI**: Lock a distinct design brief BEFORE writing components: define character/world, surface hierarchy, 1 display + 1 body + 1 mono font pair (`fontpair.co` / `chalk.ist`), color palette (`pigment.shapefactory.co`), one signature visual detail, and an asymmetric/editorial hero layout.
   - **UX Laws (`lawsofux.com`)**: Enforce Fitts's Law (touch targets >= 44px), Hick's Law (reduce visible top-level choices), Jakob's Law, and Doherty's Threshold (<400ms feedback).
3. **Vercel Web Interface Guidelines (`web-design-guidelines`)**:
   - Enforce `font-variant-numeric: tabular-nums` on all dynamic counters, tables, and prices.
   - Enforce `text-wrap: balance` on headings and `text-wrap: pretty` on body paragraphs.
   - Always provide visible `:focus-visible` keyboard rings, sync filter/tab state to URL query params, and prevent layout shift (CLS = 0) with exact-dimension skeletons.
4. **The `Unslop` 9-Pass Redline Protocol (`heydamir/unslop`)**:
   - When refactoring or polishing an existing/vibecoded UI, audit first and execute fixes in this strict 9-pass order:
     `Pass 1: Spacing -> Pass 2: Color -> Pass 3: Icons -> Pass 4: Copy (cut hype/fluff) -> Pass 5: Typography -> Pass 6: Layout -> Pass 7: Signature Details -> Pass 8: Product Visuals -> Pass 9: Motion`.
5. **Interaction State Machine & Error Flows (`designer-skills`)**:
   - Every interactive component or form MUST explicitly model all states and transitions (`Idle -> Loading -> Success -> Empty -> Error -> Disabled/Rate-Limited`) with clear user recovery paths.
6. **On-Demand Automated CLI Check (`npx -y`)**:
   - After editing UI files, automatically run `npx -y impeccable detect` on the modified path and fix all P0/P1 visual/structural findings before finishing.

## 2. Animation, Motion Engineering & Cinematic Heroes (`Emil Kowalski` + `MotionSites`)
1. **Restraint First**: High-frequency productivity/keyboard actions require near-instant (`0-120ms`) response; reserve rich choreography for marketing heroes and key storytelling moments.
2. **Physics & Easing Rules**:
   - Never use `linear` or browser default `ease-in-out` for UI entrances. Use custom exponential ease-out (`cubic-bezier(0.22, 1, 0.36, 1)`) or spring physics.
   - Animate ONLY compositor-friendly properties (`transform`, `opacity`, `clip-path`, `filter`).
   - Always implement `@media (prefers-reduced-motion: reduce)` fallbacks and clean up event/scroll listeners on unmount.
3. **Animation Engine Escalation Matrix**:
   - **Micro-interactions / Hover / State**: Pure CSS transitions + custom easing tokens.
   - **Layout Projections / Shared Elements / Gestures**: `Motion` (`motion/react` / Framer Motion).
   - **Complex Timelines / ScrollTrigger / Scrollytelling**: `GSAP` (`gsap.com`) or `Anime.js` (`anime.js`).
   - **SVG Path Drawing**: `Vivus SVG` or CSS `stroke-dashoffset`.
   - **Lightweight Pseudo-3D**: `Zdog` (`zzz.dog`).
   - **Full WebGL / Shaders / 3D Scenes**: `Three.js` / React Three Fiber + `threeui.com` + `Theatre.js` (`theatre.js` for keyframe choreography).
4. **Cinematic Landing Page Recipes (`MotionSites` Protocol)**:
   - When tasked with building an award-level/cinematic landing page, use proven high-craft recipes: word-by-word blur/mask headline reveals, liquid glass surfaces (`backdrop-filter` + specular border), seamless muted hero video loops or mouse-scrubbed frames, spotlight cursor reveals, and depth carousels.
