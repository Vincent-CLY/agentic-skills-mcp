# MASTER FRONTEND DESIGN, MOTION PHYSICS & ANTI-SLOP ENGINE

## 1. Anti-AI-Slop Hard Floor (`Impeccable` + `Hallmark` + `taste-skill` + `frontend-design`)
1. **Banned AI Slop Patterns**:
   - NEVER use default purple/indigo/blue neon gradients, generic centered 3-card icon grids, uniform rounded-xl cards everywhere, or fake "Lorem ipsum" copy.
   - NEVER invent arbitrary spacing or raw hex colors outside CSS variables/design tokens.
2. **Token, Palette & Aesthetic Setup (`Hallmark` / `taste-skill` / `ui-ux-pro-max`)**:
   - **Greenfield UI**: Lock a distinct direction BEFORE writing components: define surface hierarchy, 1 display + 1 body + 1 mono font pair (`fontpair.co` / `chalk.ist`), color palette (`pigment.shapefactory.co`), and an asymmetric/editorial hero layout.
   - **UX Laws (`lawsofux.com`)**: Enforce Fitts's Law (touch targets >= 44px), Hick's Law (reduce visible top-level choices), Jakob's Law, and Doherty's Threshold (<400ms feedback).
3. **Vercel Web Interface Guidelines (`web-design-guidelines`)**:
   - Enforce `font-variant-numeric: tabular-nums` on all dynamic counters, tables, and prices.
   - Enforce `text-wrap: balance` on headings and `text-wrap: pretty` on body paragraphs.
   - Always provide visible `:focus-visible` keyboard rings, sync filter/tab state to URL query params, prevent layout shift (CLS = 0) with exact-dimension skeletons, and handle empty/loading/error states gracefully.
4. **On-Demand Automated CLI Check (`npx -y`)**:
   - After editing UI files, automatically run `npx -y impeccable detect` on the modified path and fix all P0/P1 visual/structural findings before finishing.

## 2. Animation & Motion Engineering (`Emil Kowalski` Protocol)
1. **Restraint First**: Not everything should animate. High-frequency keyboard/productivity actions require near-instant (`0-120ms`) response.
2. **Physics & Easing Rules**:
   - Never use `linear` or browser default `ease-in-out` for UI entrances. Use custom exponential ease-out (`cubic-bezier(0.22, 1, 0.36, 1)`) or spring physics.
   - Animate ONLY compositor-friendly properties (`transform`, `opacity`, `clip-path`, `filter`).
   - Always implement `@media (prefers-reduced-motion: reduce)` fallbacks and clean up event/scroll listeners on unmount.
3. **Animation Engine Escalation Matrix**:
   - **Micro-interactions / Hover / State**: Pure CSS transitions + custom easing tokens.
   - **Layout Projections / Shared Elements / Gestures**: `Motion` (`motion/react` / Framer Motion).
   - **Complex Timelines / ScrollTrigger / Scrollytelling**: `GSAP` (`gsap.com`) or `Anime.js` (`anime.js`).
   - **SVG Path Drawing**: `Vivus SVG` or CSS `stroke-dashoffset`.
   - **Lightweight Pseudo-3D**: `Zdog` (`zzz.dog`).
   - **Full WebGL / Shaders / 3D Scenes**: `Three.js` / React Three Fiber + `threeui.com` + `Theatre.js` (`theatre.js` for keyframe choreography).
